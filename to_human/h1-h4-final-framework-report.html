最终框架报告：Stateful Value-Signal Research Loop

基于 H1-H4 验证，对 /autoresearch 的人机交互机制做最终综合：长期 AI 技能的本质是状态化 artifact、价值信号交换、证据/意义双循环，以及报告驱动的人类治理。

H1-H4 全部支持研究对象：/autoresearch日期：2026-07-06

1. 最终定义

Stateful Value-Signal Research Loop：一种长期 AI 交互模式。人类提供价值信号与治理，AI 维护 artifact-mediated state，内循环生产证据，外循环生产意义，进展报告关闭人类方向控制循环。

Human Value Signal→ Artifact-Mediated State→ Inner Loop Evidence→ Outer Loop Meaning→ Governance Report→ Updated Value Signal

2. 四个已验证机制

H1

Artifact Interfaces

Artifact 是消费者界面，不是被动文件。

H2

Value-Signal Exchange

人控制价值函数，AI 生产证据与综合。

H3

Epistemic Loops

内循环生产证据，外循环生产意义。

H4

Governance Reports

报告是人类治理接口，不只是展示。

3. 第一性原理：目标、信息、行动、反馈

原语人类责任AI 责任关键 Artifact
Goal定义目标、受众、成功标准转化为研究问题和假设research-state.yaml
Information提供背景和价值判断搜集文献、生产证据、压缩发现literature/, experiments/, findings.md
Action设定边界，批准高风险动作自主执行可逆、低风险、常规研究动作experiments/, data/
Feedback通过报告更新方向将反馈写回状态并重新排序to_human/, research-log.md

4. 设计原则

原则 A：先设计消费者，再设计文件

每个 artifact 都要声明 producer、consumer、compression level、decision enabled、failure if missing。

原则 B：通过价值函数控制，而非步骤控制

人类最重要的输入是 objective、audience、success criteria、constraints、feedback cadence。

原则 C：分离证据生产与意义生产

内循环不要承担叙事判断，外循环不要脱离证据空转。

原则 D：报告必须形成决策面

报告要让人能判断 deepen、broaden、pivot、conclude，而不是只展示活动。

6. 诊断矩阵

失败模式症状根因修复
输出无价值很多内容但不知有何用价值信号弱明确目标、受众、成功标准
有活动无理解实验很多，findings 很薄外循环弱强制综合、模式聚类、方向判断
有框架无证据叙事漂亮但无支撑内循环弱补 protocol、结果、案例或数据
人类瓶颈频繁小审批步骤控制过强只审批高风险/不可逆动作
AI 漂移越来越偏离目标报告少或价值信号过期生成治理报告，刷新优先级
虚假确定性弱证据被写成强结论报告缺少置信度标注 evidence type 与 confidence

7. 对 /autoresearch 的最终判断

/autoresearch 的设计价值不在于“自动做研究”这个表层描述，而在于它把长期开放式研究转换为一个可治理的状态机：artifact 负责记忆和接口，价值信号负责方向，双循环负责认知节奏，报告负责人类控制面。

8. 研究收束建议

当前 H1-H4 已经形成自洽模型，足以收束成一篇方法论文章。若目标是学术论文，还需要进一步补充外部文献和案例验证；若目标是技能设计方法论，当前证据已经足够进入文章草稿阶段。
